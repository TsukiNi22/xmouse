What you copy, drop or drag goes to the other devices of the network.

## Clipboard {#clipboard}

Text, images and files copied on a member land in the clipboard of the others: paste them there like local ones. Copied files up to 64 MiB are fetched at once (`clipboardFilesLimit`). A phone gets the text.

## Files {#files}

| Way | How |
| --- | --- |
| On the map | Drop files on a device of the Layout page |
| Menu | **Send files to...** (panel, tray, right click on the map) |
| To an edge | Drag a file to the border of the screen: a **drop shelf** opens there and sends it to the device on the other side |

Received files go to `Downloads/xmouse`, never over an existing file; the **Activity** page lists the transfers.

## Links {#links}

**Send a link to...** opens a web page on another member: asked there by default (`links`: ask, open at once, or refuse).

## Windows {#windows}

With **Windows can move between devices (whole network)** on, a window dragged on an edge (GNOME with the extension, Windows), or chosen with **Show a window of this device on...**, goes to the device on the other side: shown and driven there, given back by closing it. The document it shows can be opened there instead.
