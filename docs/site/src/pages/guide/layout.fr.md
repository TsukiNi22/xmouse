La page **Layout** montre chaque écran de chaque membre sur un même plan, identique sur chaque appareil.

## Les placer {#place}

Glissez chaque appareil là où sont ses écrans sur votre bureau : les bords s'aimantent aux autres. Passé un bord qui touche un autre écran, votre curseur continue sur cet appareil, avec votre clavier : mouvements, clics, molette et touches vont là où est le curseur. Un appareil hors ligne est un mur.

> [!TIP]
> <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>Maj</kbd>, ou **Bring my cursor back** (panneau, zone de notification), ramène le curseur aussitôt.

## La carte en direct {#map}

La carte montre où est le curseur de chaque membre, en direct. Glissez le fond pour déplacer la vue, la molette pour zoomer, **Recenter** dans le coin pour tout revoir ; la vue ne bouge jamais toute seule.

## Profils {#profiles}

Un **profil** enregistre la disposition sous un nom (bureau, voyage...) : appliquez-le sur tous les membres d'un coup, supprimez-le quand il ne sert plus.

## Montrer où vous êtes {#presence}

| Action | Effet |
| ------ | ----- |
| **Look here** | Une onde là où est votre curseur, sur son écran et sur chaque carte |
| **Laser** | Une traînée rouge sur les écrans que votre curseur traverse |
| **Follow** | Une flèche au bord de votre écran montre le curseur d'un membre |

Ensuite : [le téléphone](page:phone#home).
