Ce que vous copiez, déposez ou glissez va vers les autres appareils du réseau.

## Presse-papiers {#clipboard}

Le texte, les images et les fichiers copiés sur un membre arrivent dans le presse-papiers des autres : collez-les là comme des locaux. Les fichiers copiés jusqu'à 64 Mio sont récupérés tout de suite (`clipboardFilesLimit`). Un téléphone reçoit le texte.

## Fichiers {#files}

| Moyen | Comment |
| ----- | ------- |
| Sur la carte | Déposez des fichiers sur un appareil de la page Layout |
| Menu | **Send files to...** (panneau, zone de notification, clic droit sur la carte) |
| Vers un bord | Glissez un fichier vers le bord de l'écran : une **étagère** s'ouvre là et l'envoie à l'appareil de l'autre côté |

Les fichiers reçus vont dans `Downloads/xmouse`, jamais par-dessus un fichier existant ; la page **Activity** liste les transferts.

## Liens {#links}

**Send a link to...** ouvre une page web sur un autre membre : demandé là-bas par défaut (`links` : demander, ouvrir tout de suite, ou refuser).

## Fenêtres {#windows}

Avec **Windows can move between devices (whole network)** activé, une fenêtre glissée sur un bord (GNOME avec l'extension, Windows), ou choisie avec **Show a window of this device on...**, va sur l'appareil de l'autre côté : affichée et pilotée là-bas, rendue en la fermant. Le document qu'elle montre peut être ouvert là-bas à la place.
